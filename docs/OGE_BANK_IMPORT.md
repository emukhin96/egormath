# Повторный импорт банка ОГЭ Остромогильского

Профиль требует исходный OCR TEX вместе с его каталогом изображений и
интерактивный PDF сборника с якорями `task::` и `ans::`.

```bash
./venv/bin/python -m public_html.problems.textbook_parser \
  --profile ostromogilsky \
  --tasks '/путь/oge-9 tasks and ans.tex' \
  --answers-pdf '/путь/Остромогильский — открытый банк ОГЭ.pdf' \
  --output /tmp/oge-import
```

Результат: `import.json`, `review.tsv`, `report.md` и папка `images` со
всеми используемыми изображениями. CLI не изменяет Django-базу. JSON
загружается через страницу импорта; содержимое `images` можно упаковать
в ZIP и сопоставить на странице партии. Не помещайте приватную базу,
резервные копии и исходные учебные материалы в Git.

Полный CLI выполняет восстановление по PDF после первичного разбора TEX.
Внутренняя функция `bundle_for` возвращает промежуточный результат; для
переносимого полного экспорта нужно использовать CLI.

## Контроль исходного сборника

Ожидаются 4003 уникальных номера и 3943 ответа. Шестьдесят заданий №24
на доказательство не имеют числового авторского ответа. Каждый номер
получает метку `OGE_2026_NN`. Практическая часть состоит из 74 блоков по
пять вопросов; блок должен сохранять общий текст и картинки при добавлении,
перестановке, копировании, скрытии и удалении из листка.

После любого изменения сравнивайте не только количества: проверяйте
условия, формулы, номера вариантов, рисунки, ответы, соседние задачи и
PDF-вёрстку. Отсутствие `Overfull` не доказывает отсутствие обрезаний:
контролируйте также границы изображений на страницах.

Исправления известных исключений находятся в
`public_html/problems/data/ostromogilsky_*.json`. Они привязаны к исходному
тексту PDF. Последний слой дополнительно требует точного совпадения
ожидаемого OCR-текста и списка изображений. Не меняйте эти проверки на
безусловную подмену: другая редакция сборника требует новой сверки.

Сверка содержимого не одобряет черновики автоматически и не загружает
задачи в рабочий каталог.

## Метки, теги и маски при загрузке

Номер в ключе Остромогильского определяет метку `OGE_2026_NN`.
Это проверяется при разборе, экспорте JSON, создании черновиков и загрузке
в каталог. Отсутствующая метка в справочнике или конфликт номера у уже
существующей задачи останавливает загрузку с понятной ошибкой.

Автоматические теги дополняют исходные и редакторские:

- №22: «задача с параметром», «построение графика»;
- №24: «геометрическая задача на доказательство».

Маски №1–19 формируются обычным кодом из окончательного авторского ответа
при загрузке в каталог, без ИИ и платных API. Предварительно сохранять их
в черновиках не требуется: правки ответа до импорта автоматически учитываются.
При повторном импорте заполняются только пустые маски, сохранённый выбор
учителя не заменяется. Форматы описаны в `docs/ANSWER_FORMATS.md`.

Для текущих 4003 задач: 642 последовательности цифр и 2427 десятичных масок.
Ответы 3.5 и 3.5.1 содержат несколько значений и требуют ручного выбора.
Для №20–25 маски автоматически не назначаются: числовая маска не заменяет
проверку развёрнутого решения, графика или доказательства. Учитель может
создать нужную маску отдельно.
