# Подготовка Феоктистова: алгебра, 9 класс

Профиль `feoktistov` предназначен для самостоятельных, контрольных работ
и тестов с локальными номерами. Проверенный скан: И. Е. Феоктистов,
«Алгебра. 9 класс. Дидактические материалы», Мнемозина, 2018, 3-е издание.

## Подготовка пакета

```bash
./venv/bin/python tools/prepare_feoktistov.py \
  --tex '/путь/к/OCR.tex' \
  --pdf '/путь/к/книге.pdf' \
  --output tmp/feoktistov9-prepared
```

Команда требует PyMuPDF (`pymupdf`), читает исходники и папку `images` рядом
с TeX. Она проверяет SHA-256 обоих файлов перед применением исправлений
конкретного скана. Произвольный PDF нельзя обрезать по сохранённым координатам.
В результате создаются `import.json`, `images.zip`, TSV и отчёт. База данных
не изменяется. В ZIP входят только использованные иллюстрации.
Каталог `tmp/` исключён из Git. Если PyMuPDF отсутствует, команда завершится
с инструкцией установки без создания частичного пакета.

Отдельный парсер без восстановления картинки:

```bash
./venv/bin/python tools/textbook_parser.py --profile feoktistov \
  --tasks '/путь/к/OCR.tex' --output tmp/feoktistov9-parse
```

В интерфейсе «Импорт → Новая партия» доступен профиль Феоктистова для одного
TeX с ответами в конце. Для проверенного скана предпочтителен подготовленный
JSON вместе с ZIP: исходная папка Mathpix не содержит рисунка 13, а задача
с отсутствующим изображением не должна попасть в каталог.

## Контроль структуры

В проверенном исходнике выделяются 1036 черновиков:

- 25 самостоятельных работ: 704 задачи;
- 7 контрольных работ: 176 задач;
- 13 тестов: 156 вопросов и 156 табличных ключей.

Всего 154 варианта. Самостоятельные и контрольные работы имеют
подготовительный вариант и варианты 1–3; тесты — варианты 1–2.
`feoktistov_variant_numbers` сохраняет полный список номеров каждого
варианта; `feoktistov_structure_issues` — пропуски и нарушения порядка.
Эти счётчики проверяют структуру OCR, а не математическую точность условий.

Ключ задачи включает тип, номер работы, вариант и локальный номер:
`sr/01/prep/001`, `kr/01/v2/005`, `test/01/v1/002`.
Повторяющиеся названия тем не объединяют разные работы. Каждая работа
становится подборкой, её варианты — рубриками, включая подготовительный.
Отображаемая нумерация внутри листка остаётся сквозной; локальный номер
книги хранится в ссылке на источник.

## Исправления и сохранение содержания

- Для точного SHA-256 проверенного TeX восстанавливается заголовок СР-1.
- Рисунок 15 связывается с правильным файлом, несмотря на OCR-подпись «16».
- Рисунок 13 извлекается из PDF-страницы 108 (печатная с. 107).
  Книжная подпись обрезается, как у соседних рисунков Mathpix.
  Контрольная сумма и координаты сохраняются в диагностике пакета.
- В тесте 1 вопросы 2–5 каждого варианта получают общее условие и график.
  Каждый вопрос можно использовать отдельно; рисунок повторяется намеренно.
- Четыре варианта ответа остаются в условии, выбор 1–4 хранится в маске
  `choice`. OCR-списки `enumerate` не становятся отдельными задачами.
  Для вопросов с четырьмя числами внутри формулировки добавлены явные метки.
- По PDF исправлены разорванный ответ СР-1, вариант 3, № 1б и буква
  параметра в ответе КР-1, вариант 2, № 2. Исправления действуют только
  для проверенной контрольной суммы исходника.
- По печатным с. 168–170 восстановлены границы ответов СР-12, варианта 2
  СР-14 и заголовок варианта 3 СР-17, повреждённые OCR. Исходные фрагменты
  этих работ сохранены в `feoktistov_original_answer_works`.
- Теория, методические комментарии и поурочное планирование не импортируются
  как задачи. Их перенос требует отдельного формата материала.

## Сверка перед каталогом

Все строки создаются со статусом «Не проверена». Ответы СР/КР распознаются
консервативно: номер внутри формулы не считается новой задачей. OCR часто
склеивает соседние ответы внутри одной формулы, поэтому все эти строки
имеют предупреждение о проверке границ авторского материала. Полные исходные
абзацы сохраняются в `feoktistov_raw_answer_groups` в диагностике — по
работе и варианту, чтобы неполное автоматическое сопоставление не теряло
источник для редактора. Неоднозначные фрагменты могут остаться в ответе
предыдущего номера; их нужно распределить при сверке.

Помимо общего предупреждения, отдельные строки получают сообщения о
пустой группе ответов, возможном следующем номере в ответе, обломке
заголовка варианта и ненайденном авторском ответе. Пустая группа попадает
в `feoktistov_structure_issues`; повторный ключ группы останавливает разбор.
`feoktistov_answer_anomalies` содержит конкретные замечания по ключам задач.
Сводка команды выводит число задач СР/КР без авторского материала и
распределение по работам (`feoktistov_missing_answers_by_work`), а список
ключей хранится в `feoktistov_missing_answer_ids`.

Наличие табличного ключа теста также не подтверждает точность OCR условия:
перед одобрением сверяются коэффициенты, степени, знаки и четыре варианта
ответа. Доказательства и построения могут не иметь авторского ответа.

Проверять сначала СР-1, КР-1, тест 1, затем остальные работы. Для каждой:
условия и подпункты → ответы → темы → рисунки → маски → статус.
Источник относится к 9 классу повышенного уровня, но охватывает темы,
которые в базовом курсе встречаются в 10–11 классах. Темы назначаются по
содержанию, без ограничения базовой программой девятого класса.

Подготовка пакета и пробная партия не означают публикацию книги. Полная
постраничная математическая сверка — отдельный этап перед загрузкой
одобренных задач в каталог.

## Результат технической проверки

Пробная партия: СР-1, КР-1 и тест 1 — 68 задач. В отдельной локальной
базе проверены загрузка JSON/ZIP, создание подборок с рубриками вариантов,
повторное подтверждение без дубликатов и ученическая проверка выбора ответа.
В основной локальной базе партия остаётся черновиком, без задач в каталоге.

Первичная локальная проверка собрала шесть документов (ученик/учитель для
трёх работ) и таблицу ответов СР-1. Общая правка переноса длинных ответов
из этого PR исключена: она требует отдельной проверки на старых книгах.
Длинные ответы пока могут выходить за рамки PDF; до выдачи такого листка
нужна проверка вёрстки. Профиль импорта не меняет генератор PDF других книг.
Удалённая компиляция через API не подтверждена: автоматическая проверка
разрешений отклонила передачу исходников и ключа сервису. Локальная проверка
использовала временное сопоставление установленных шрифтов CMU и не заменяет
проверку точной конфигурации сервера.

После правок ревью локально собраны 15 документов по 47 задачам: student,
teacher и answers для СР-12, СР-14/вариант 2, СР-17/вариант 3, КР-5/вариант 1
и задачи с рисунком 13. Ошибок TeX и отсутствующих символов нет;
у этих ответов дополнительных переполнений не обнаружено.

Полный пакет содержит два явно помеченных незакрытых математических
фрагмента в ответах: `sr/03/prep/001` (б) и `sr/10/prep/003` (б).
После исправления границ число задач СР/КР без авторского материала
снизилось с 243 до 198 из 880; в эту цифру входят и доказательства без
напечатанного ответа. Также 16 строк отмечены несовпадением подпунктов условия и ответа,
одна — невозможностью распределить авторский материал по подпунктам.
Это очередь редакторской сверки, а не готовые к публикации ответы.
