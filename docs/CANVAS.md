# Доска для записей к задаче

Ученик записывает решение «от руки» (мышь, стилус) прямо под задачей в
задании; учитель видит доску при проверке и оставляет пометки поверх теми
же инструментами. Холст — вспомогательная функция: сервер только хранит и
отдаёт JSON, ничего не рендерит и не пересчитывает.

Подробная спецификация и история решений — в проекте Claude
(«Холст: спецификация и план внедрения»); здесь — то, что нужно, чтобы
не сломать при правках.

## Где что лежит

| Файл | Роль |
| --- | --- |
| `canvas/models.py` | `CanvasPage`: страница = строка, оба слоя — JSON-поля, лимиты как константы |
| `canvas/validation.py` | Схема элемента и лимиты; всё, что пришло с клиента, проходит здесь |
| `canvas/services.py` | Права (`assignment_access`), заморозка при отправке, лимиты страниц, статистика для строк задач |
| `canvas/views.py` | Три JSON-эндпоинта: страницы, сохранение слоя, удаление пустой последней |
| `canvas/urls.py` | Подключено как `assignments/<pk>/canvas/<task_id>/` (`core/urls.py`) |
| `canvas/context_processors.py` | `canvas_enabled` для шаблонов |
| `static/js/canvas.js` | Весь интерфейс: инструменты, страницы, фоны, undo/redo, автосохранение |
| `templates/canvas/_toggle.html` | Тумблер учителя «Показать доски для записей» |
| `canvas/management/commands/canvas_stats.py` | Сводка по размеру и числу страниц |
| `canvas/boards.py`, `templates/canvas/boards.html`, `static/js/boards.js` | Дашборд «Доски»: до 15 учеников листка на одном экране, `progress/<id>/boards/` |

Встраивание: `<div data-canvas data-url="{% url 'canvas:pages' … %}"
data-role="student|teacher|viewer" data-pages="N">` — скрипт строит панель сам.
`viewer` — только просмотр (живой обзор, диалог прогресса); если на той же
странице есть виджет `teacher` с тем же `data-url`, viewer прячется и лишь
просит редактор перечитать данные.

## Панель инструментов: статичная структура

Панель строится один раз на страницу (`buildToolbar`) и дальше только
синхронизирует состояния (`syncToolbar`): набор, число и порядок кнопок не
зависят от инструмента и выделения. Действия над выделением, слоты цветов
(6 у карандаша и у маркера), три толщины, селекты клетки и начала координат
всегда на месте и лишь выключаются (`disabled`), когда неприменимы. Так
рабочее поле не сдвигается при клике по элементу или смене инструмента.
Не добавляйте кнопок, которые появляются по условию, — это и было причиной
«скачков» поля в первой версии.

## Правила доступа

- Слой ученика открыт, пока `assignment.is_editable_by_student`
  («Выдано», «Возвращено»). Слой учителя открыт всегда — учитель пишет и во
  время работы ученика. Слои лежат в разных полях и сохраняются по
  отдельности (`update_fields`), поэтому одновременная работа конфликтов не
  даёт; конфликт возможен только между двумя вкладками одного человека — его
  ловит версия слоя (409 с актуальными данными). Фон страницы пишет только
  тот слой, который её создал.
- Свои страницы учитель добавляет только после отправки работы
  (`Access.can_add_pages`), иначе нумерация у двоих разъедется.
- При отправке работы (`submit_assignment`) страницы замораживаются
  (`locked_at`): после возврата ученик пишет на новой странице.
- Страницы, добавленные учителем, сразу закрыты для правок ученика.
- Непустой слой ученика считается ответом в прогрессе задания; пустая
  страница и одни пометки учителя не увеличивают счётчик.
- Ученику слой учителя отдаётся в любом статусе; тумблер «Скрыть пометки
  учителя» (localStorage `canvas-hide-teacher`) по умолчанию выключен.
- Чужой слой клиент забирает `GET pages` с `If-None-Match` (ETag —
  версии слоёв, 304 без тела) и подменяет точечно (`merge`), свой слой не
  трогая. Ученик опрашивает раз в 10 с, только пока доска открыта и вкладка
  видна; учитель на странице проверки — через живой обзор (5 с). Ответ на
  сохранение несёт `other_version` — версию чужого слоя, чтобы пишущий узнал
  о новых пометках без опроса. Страница с новыми пометками, на которой
  ученик не стоит, помечается точкой на вкладке.
- Лимиты: 5 незамороженных страниц ученика, 2 страницы учителя, 10 всего;
  2000 элементов на слой, 4000 точек в штрихе, 512 КБ JSON.
- Удалить можно только пустую последнюю страницу.

## Формат элемента

```json
{"id":"k3f9a1","t":"path","c":"#1d4ed8","w":4,"p":[[120,340],[124,338]],"g":"grp1"}
```

`t` — `path` (карандаш), `hl` (маркер), `line`, `dot` (+`l` — подпись
координат на плоскости), `circle` (центр, точка окружности), `rect`
(квадрат — тот же тип), `tri`, `para` (три вершины), `fn` (заготовка
графика: `k` = `parabola|abs|sqrt|hyperbola`, `p` = опорная точка и образ
точки (1; 1)). Координаты целые в логической странице 1000×1000; `g` —
группа. Фон страницы: `blank|grid|grid_large|plane`, для плоскости
`background_options = {cell: 25|50, origin: center|bottom_left, square: true}`.
`square` сохраняется при смене фона. У старых страниц без этого признака
сохраняются исходные координаты 1000×750: при показе в квадрате слой и оси
смещаются вместе, рисунок не растягивается и не обрезается.

## Предохранители

- `CANVAS_ENABLED=0` в `.secrets/` (или переменная окружения) прячет панель
  и закрывает эндпоинты (503) — перезапуск без деплоя кода.
- Тумблер учителя «Показать доски для записей» включён по умолчанию
  (выключает только явное `canvas-show = '0'` в localStorage); выключенный —
  доски не грузятся и не рендерятся. Доска с `data-pages="0"` не
  запрашивается, пока учитель не нажмёт кнопку.
- Фон страницы правит только тот, кто её создал: у чужих страниц и в режиме
  просмотра вместо селектов фона — одна подпись «Фон: …».
- Тело больше 512 КБ отсекается по `Content-Length` до разбора JSON.
- Сохранение с клиента: через 1 с после паузы, не чаще раза в 5 с при
  непрерывном письме; при обрыве связи — повторы через 3/10/30 с и черновик
  в localStorage, который досылается при следующем открытии.
- Отправка задания, завершение и возврат проверки ждут текущие запросы
  и последние изменения всех страниц. При ошибке отправка блокируется,
  локальный черновик остаётся. Пустые промежуточные страницы тоже
  сохраняются по порядку; восстанавливаются и ещё не созданные на сервере.
- Запись/удаление холста и смена статуса задания используют общий замок
  строки задания, чтобы проверка прав не устарела во время запроса.
- Живой обзор учителя использует тот же опрос раз в 5 с: в подпись
  `answer_versions()` входит `Max('canvas_pages__student_updated_at')`,
  сам JSON в фрагменты не попадает.
- `manage.py canvas_stats` — число страниц, средний и максимальный размер,
  доля ответов с холстом. Запускать вручную первые недели после выкатки.

## Дашборд «Доски»

`assignments/progress/<worksheet>/boards/?group=` — карточки не больше
`BOARDS_MAX = 15` учеников (сначала те, где недавно писали; остальные —
«ещё N не поместились»). Один опрос на экран: `boards/live/?since=` раз в
5 с одним индексированным запросом возвращает только страницы, изменённые
после `since`; подпись ответа (ETag) — статусы учеников и сводка по
версиям страниц, поэтому пустой опрос — 304 без тела. Миниатюры рисует
`EgorCanvas.render(canvas, page, size)` — чистая функция без панели и
обработчиков, перерисовываются только изменившиеся. Клик по карточке
открывает `<dialog>` с обычным виджетом `teacher` (canvas.js поднимает его
через MutationObserver); пока диалог открыт, сетка опрашивается раз в 15 с.
Через 30 минут без движения мыши опрос останавливается («Продолжить»).

## Горячие клавиши (как в Holst)

Срабатывают по физической клавише (`e.code`), поэтому в русской раскладке тоже: З = P, У = E, М = V.
V — выделение/перемещение, P — карандаш, Shift+P — маркер, E — ластик,
O — прямоугольник, S — окружность, L — отрезок, Ctrl+Z / Ctrl+Shift+Z,
Ctrl+G / Ctrl+Shift+G — группировать/разгруппировать, `]` / `[` — на
передний/задний план, Delete — удалить выделенное, стрелки — сдвиг на 1
(с Shift — на 10), Esc — снять выделение и отменить недостроенную фигуру.

## Проверка

`manage.py test canvas` — права, лимиты, версии, заморозка, шаблоны.
`node --test tools/test_canvas.js` — медленное сохранение, ошибки сети и
сервера, отправка формы, порядок страниц, черновики, viewer и отмена ластика.
Эти проверки также запускает CI; Node нужен только для тестов разработки.
Интерфейс проверять руками в Chrome/Firefox мышью и на iPad со стилусом:
DevTools не воспроизводит отсечение ладони и прокрутку страницы при
рисовании.

## Интерфейс доски

На публичных страницах используется название «Доска для записей»;
технические имена приложения, URL и `data-canvas` остаются прежними.
Кнопка открытия находится рядом с «Фото решения». Крестик закрывает панель
без удаления рисунков; корзина удаляет пустую последнюю страницу, включая
единственную. Для непустой или замороженной страницы корзина неактивна с
подсказкой. После очистки и undo её состояние обновляется сразу.

Панель ограничена шириной 600 px, поле квадратное и сужается на небольших
экранах. Значки имеют подписи для скринридера и подсказки; формулы в кнопках
графиков рисует тот же KaTeX, что и условия задач. В координатной плоскости
список размера клетки неактивен. Переключатель — «Привязывать к сетке».

Ctrl/Cmd или Shift при клике добавляют объект к выделению или снимают его.
Рамка с модификатором добавляет объекты и целые группы. Цвет, толщина,
перемещение и удаление применяются ко всем выделенным объектам; изменения
можно отменить.
