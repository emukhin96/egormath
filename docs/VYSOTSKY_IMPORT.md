# Подготовка Высоцкого: теория вероятностей, 8–9 классы

Профиль `vysotsky` — И. Р. Высоцкий «Дидактические материалы по теории
вероятностей. 8–9 классы» (МЦНМО, 2018, электронное издание, 224 с.).
OCR — Mathpix, `Высоцкий дидактические материалы теорвер 8-9 класс.tex`,
SHA-256 `bd22bdd47957a80593ff0e1f41993bde36a8180e470498ff92d6bf823ed035e3`;
скан — `Дидактические материалы статистика 8-9 класс.pdf`, SHA-256
`ec4c42c5a527a467e79a84948ea67d65a9f4b5065ba16d2882fc2798f2dbca7c`
(текстовый слой с битыми шрифтами; страница PDF ≈ страница книги + 1,
в разделе карточек есть пустые вставные страницы; номер страницы PDF
надёжнее брать из имени рисунка Mathpix: `…-130_342_363_986_767` — с. 130).

## Разбор

```bash
./venv/bin/python tools/textbook_parser.py --profile vysotsky \
  --tasks '/путь/к/Высоцкий дидактические материалы теорвер 8-9 класс.tex' \
  --output tmp/vysotsky-parse
```

ZIP для партии — папка `images` Mathpix плюс шесть вырезок из скана для
ответов, потерянных OCR (`vysotsky-answer-*.png`); готовый пакет —
`artifacts/vysotsky/vysotsky-images.zip` (посторонний `Архив.zip` из папки
`images` в него не входит). В интерфейсе «Импорт → Новая партия» профиль
называется «Высоцкий».

## Структура книги

- 11 параграфов в трёх разделах, сквозная нумерация 1–396. Путь подборки —
  раздел → параграф → «Задачи для работы в классе» / «Задания для
  домашней работы» (граница — заголовок в тексте; число из
  `problems/data/vysotsky_structure.json` — контроль, расхождение уходит
  в `home_boundary_mismatch`). Основная тема — по параграфу
  (`topic` в таблице). Вводное «Пояснение.» параграфа — теория, в импорт
  не входит.
- «Пример решения», «Пример решения и обсуждения», «Пример доказательства»,
  «Указание», «Обсуждение» после условия — авторский разбор задачи перед
  ними; «Ответы» в конце книги дают ответ и к этим задачам (разбор
  остаётся впереди указания из раздела ответов).
- Звёздочка у номера («29*.», OCR — «179.*.», «239.*») — задача повышенной
  сложности (`stars = 1`).
- Карточки для индивидуальной работы И1.1 … И11.3 (по две задачи),
  самостоятельные С1.1 … С11.2 (2–3 задачи), контрольные КI.1–КI.4,
  КII.1–КII.2, КIII.1–КIII.2 (по шесть задач). Метки карточек и
  самостоятельных стоят на полях, OCR оставляет от них только номер
  варианта («1», «2\\», `\section*{3}`, «1 1.»): ключи восстанавливаются по
  порядку книги, номер варианта из OCR сверяется (`variant_series`).
  Ключ задачи — «И5.2/1», «С1.2/3», «КI.3/4». Тема задачи карточки и
  самостоятельной — тема её параграфа; у контрольных — параграф каждого
  номера по таблице `tests[].paragraphs`.
- Внутри варианта номер задачи бывает и `\item`, и «2.» в тексте пункта:
  нумерация считается по обоим, отдельно в каждом варианте.

## Аналоги вариантов

Задачи под одним номером в парных вариантах самостоятельных и контрольных
работ — аналоги: «С1.1/2» и «С1.2/2», «КI.1/4» и «КI.2/4», «КI.3/4» и
«КI.4/4» (в КI варианты 1–2 базовые, 3–4 — более содержательные, это две
разные пары). Правило `WORK_VARIANT` в `independentworks/analogs.py`
распознаёт такие ключи источника (как пары вариантов Зива), а
«Загрузить в каталог» для профиля `vysotsky` сразу вызывает
`sync_families(source_id=…)` — семьи появляются без ручного
`sync_independent_analogs`. Неполная пара (загружен только один вариант)
попадает в отчёт `incomplete` и семьи не создаёт; при догрузке второго
варианта связь появится при следующей загрузке. Карточки «И» не
связываются: задачи разных карточек одного параграфа по содержанию не
аналоги (разные вопросы, вторые задачи — разные трудные задачи).

## Нормализация OCR

- Водяной знак электронного издания («AOdV/Gns8v48cw==», «aodvncissufaciv==»)
  удаляется; варианты внутри формул — сверенными правками.
- Mathpix ведёт счётчик `enumerate` по `\item`, а в строке книги бывает
  несколько номеров («186. … 187. …»): номер пункта — следующий за
  наибольшим из счётчика и явных номеров в тексте (`renumber_lists`).
- «в п. а)» — ссылка, а не метка пункта; латинская «B)» в начале строки —
  пункт «в)»; латинские метки «a)» показываются как «а».
- Общее требование после последнего пункта отдельной строкой («Результаты
  округлите до тысячных») переносится в условие (`lifted_tails`).
- «а) и б) 25» в ответах — один ответ двух пунктов (`joint_answers`).

## Сверенные правки скана

`problems/data/vysotsky_repairs.json` — правки OCR, сверенные со сканом
(поле `source` — страница PDF), применяются только к TEX с указанным
SHA-256; каждый фрагмент обязан встречаться ровно один раз. Оба раздела
ответов переписаны по скану целиком: OCR сдвигал номера после пропусков
(в книге нет ответов к 114, 115, 189, 199, 307), терял текст рядом с
рисунками-таблицами (19 б), 20 б), 34, 35, 146 в)), путал цифры (277 а):
в книге 10/21) и терял рисунки ответов С1.2, С3.2, С4.1, С4.2, С6.2 и
КI.3 № 5 (они вырезаны из скана).

Книга без ответа у задач 114, 115, 189, 199, 307 — так в книге.
Опечатки самой книги в авторских полях не исправляются.
