# Проверка и импорт распознанного задачника

Актуальная пользовательская инструкция доступна учителю прямо на сайте:
верхнее меню **Импорт** → **Инструкция**. Она описывает ручную сверку,
четыре результата проверки, момент записи задач в рабочую базу, ограничения
отмены и формирование подборок.

## Главное о жизненном цикле

Загрузка `import.json` создаёт только `TextbookImportBatch` и
`TextbookTaskDraft`. Объекты `Task`, ссылки на источник и подборки появляются
только после подтверждения **Загрузить в каталог**. Операция атомарна: при
любом конфликте вся транзакция откатывается.

- **Не проверена** — остаётся черновиком и блокирует загрузку партии.
- **Одобрена** — будет импортирована при общей финальной команде; до неё это
  всё ещё черновик.
- **Конфликт** — требует исправления, не импортируется и блокирует партию.
- **Пропущена** — сознательно исключена, не импортируется и не блокирует
  остальные строки.

После финальной загрузки автоматического отката одним кликом нет. До неё
достаточно не запускать загрузку либо изменить статус строки. Полное описание
и последовательность сверки поддерживаются во встроенной инструкции, чтобы
редактор видел их рядом с актуальным интерфейсом.

На странице партии блок **«Предпросмотр подборок и массовая тема»** показывает,
какие разделы книги станут виртуальными листками и какие задачи войдут в каждый
из них. Там же можно выбрать тему рубрикатора и назначить её сразу всем
черновикам одного раздела. Операция не меняет статусы проверки и до кнопки
**«Загрузить в каталог»** не создаёт рабочих задач.

Пунктуация подпунктов нормализуется по тем же правилам, что при импорте листка
из `.tex`: законченное предложение с заглавной буквы сохраняет точку,
вопрос сохраняет `?`, а у фрагмента перечисления удаляются служебные `;` и `.`.
Это позволяет позже переставлять и исключать подпункты: знаки между ними и у
последнего выбранного пункта расставляет генератор листка.
