# Ященко «ЕГЭ-2027. 36 вариантов» (профильный уровень)

Профиль `yashchenko_ege` — сборник «ЕГЭ. Математика. Профильный уровень.
36 вариантов заданий» под ред. И. В. Ященко (ФИПИ — школе, 2027). OCR —
Mathpix: один TEX и папка `images`. Издание профиль узнаёт по SHA-256 TEX
(`problems/data/yashchenko_structure.json`); чужой TEX разбирается без
таблицы рисунков и сверенных правок — с предупреждениями.

| Файл | SHA-256 |
| --- | --- |
| `Ященко ЕГЭ-2027 36 вариантов.tex` | `6270385e59638aa2933de4faca20cb22b1eccdd3b76140d52cb99b721a00b535` |
| PDF скана (225 стр., без текстового слоя) | `c83fb4bf31da506940e4ba54e98ab2406d30e014d038f10f18171b4f1a168777` |

Страница PDF = странице книги: вариант N — стр. `11 + 4(N−1)` … `+3`,
ответы — 155–172 (по два варианта на странице), решения — 173–224.

## Разбор

```bash
./venv/bin/python tools/textbook_parser.py --profile yashchenko_ege \
  --tasks '/путь/Ященко ЕГЭ-2027 36 вариантов.tex' --output tmp/yashchenko
./venv/bin/python tools/yashchenko_images.py \
  --tex '/путь/Ященко ЕГЭ-2027 36 вариантов.tex' --images '/путь/images' \
  --pdf '/путь/книга.pdf' --output tmp/yashchenko
(cd tmp/yashchenko && zip -qr images.zip images)
```

В интерфейсе «Импорт → Новая партия»: компоновка «один TEX», профиль
«Ященко: 36 вариантов ЕГЭ», ZIP — `tmp/yashchenko/images.zip`
(картинки Mathpix плюс вырезки из PDF, см. «Рисунки»).

## Структура и метки

- 36 вариантов × 20 заданий = 720 задач. Ключ — `В<вариант>/<номер>`
  (`В7/14`), подборка — «Вариант N».
- Номер задания сразу даёт метку линии `EGE_PROFILE_2027_NN` (проект
  КИМ ЕГЭ-2027, 20 заданий: 1–13 краткий ответ, 14–20 развёрнутый),
  класс `GRADE_10_11` и основную тему по линии (`ege_metadata.SECTION_TOPICS`,
  как у банка Остромогильского).
- Подпункты а/б/в — у №14, 15, 18, 20 (в №15 и №18 пункт а —
  доказательство, ответа нет).
- Ответы — таблицы «Вариант N»; «а) …; б) …» делятся по подпунктам.
- Решения части 2 есть у вариантов 1, 7, 11, 17, 21, 27, 31 (49 задач).
  Каждое задание в книге кончается таблицей критериев: по ним решения
  режутся на №14–20 (таблица бывает разорвана переносом страницы —
  «Окончание табл.»). Номер берётся из пересказа условия. В разбор идёт
  текст от «Решение.» до ответа; пересказ условия и критерии не хранятся.
- Семьи аналогов: книга говорит, что варианты собраны по планам, и
  варианты 2k−1 и 2k действительно попарно однотипны (сходство условий
  внутри пары ≈ 0,9, между парами ≈ 0,3). Правило `yashchenko_ege` в
  `independentworks/analogs.py`: один номер в паре вариантов — семья
  (360 семей по 2 задачи), строится при «Загрузить в каталог».
- Маски строит загрузка в каталог по формату линии
  (`assignments/checks/ege_policy.py`, общий с банком ЕГЭ): №1–13 —
  `decimal`, №14а — `series`, №16/19 — `range`, «число единица» —
  слот и единица текстом, «да (например…)» в №20 — `yesno`, формула с
  параметром условия в №15/17/18 — `expression` с `positive`. Явные
  маски — `answer_masks` в файле правок.

## Ловушки OCR (решены в парсере)

- Маркер задания — `\item[N]` или голое «N » в начале строки; заголовок
  варианта 8 испорчен («ВАРИകΗ 8»).
- Боковые рисунки (№1, №3, графики) Mathpix ставит посреди фразы или
  после поля ответа предыдущего задания, иногда повторяя начало фразы.
  Владелец рисунка — по геометрии скана: рамки номеров заданий на
  страницах варианта (`tools/yashchenko_images.py --boxes`, 20 рамок на
  вариант; в варианте 18 одна рамка добавлена вручную) и рамка,
  ближайшая сверху к центру рисунка (`figure_owners`). Рисунок посреди
  фразы уходит в конец условия, между фразами (графики №9, №12) — на
  месте.
- Служебный текст: инструкции, «Ответ: ____», «Часть 2»,
  `\textbackslash section*`, колонтитул `\footnotetext{© 2027 …}`.
- Ответы-таблицы: вложенные `tabular`/`itemize`, `aligned` переносов
  («∪ & ∪»), жирные цифры водяного знака (`\mathbf{1 6 1}`).

## Сверка со сканом (15.11.2026)

Все 720 условий, подпункты, рисунки и ответы и все 49 решений сверены со
страницами PDF (8 проверяющих по 6 вариантов / 3–4 варианта решений).
Найденное внесено в `problems/data/yashchenko_repairs.json`
(`text_fixes`, 193 правки готовых полей, у каждой — страница PDF):
потерянные минусы у границ отрезков (В1/14, В33/14, В11/14 в решении,
В19/14б в ответе), неверные основания/показатели (В20/16, В22/16,
В32/7), данные условия (В8/17 R = 10 Ом, В23/17 r = 1,5 Ом, В9/9),
единицы латиницей, слипшиеся ответы №19, мусор OCR.

- Страница 210 OCR потеряна целиком: конец решения В27/14 и начало
  В27/15 транскрибированы со скана, рисунок числовой окружности вырезан
  из PDF.
- Рисунки из PDF (`derived_figures`): В3/3 (Mathpix не выгрузил),
  В3/2 и В7/19 (обрезка захваченного текста), В24/3 (обрезан снизу).

## Канон оформления (замечания 15.11.2026)

Последний проход профиля (`typography` в `yashchenko_parser.py`) после
сверенных правок, для всех полей — условий, подпунктов, ответов, решений:

- годы — текстом («в июле 2031, 2032 и 2033 годов»), градусы — формулой
  (`$30^{\circ}$`, `$21{,}5^{\circ}\mathrm{C}$`);
- строчная формула с дробью или вложенной степенью — `\displaystyle`,
  дробь в показателе — `^{\textstyle …}` (в ответах не ставится: его не
  знает разбор маски);
- без пустых строк и отступов строк (списки условий №13 — подряд);
- точка, потерянная OCR перед «Найдите…» и в конце условия, `?` из
  формулы — после неё.

Проверено сканером по сохранённым черновикам партии: 0 нарушений.
На сайте таблица `tabular` — блок: переносы строк вокруг неё
убираются (`web_tex`), а в списках (`table.list`) её ячейки сохраняют
рамку и отступы (`input.css`, `.tex-table`).

## Проверка отрисовки

- KaTeX: все 5553 формулы сохранённых черновиков партии рендерятся без
  ошибок.
- PDF (агент `tex-checker`, штатный `worksheet_to_tex`, LaTeX API и
  локальный lualatex): условия всех 720 задач, ответы и 49 решений
  собираются. По ходу исправлены две общие ошибки импорта:
  `wrap_bare_math` оборачивал `\hline` таблицы в `$…$` (Misplaced
  \noalign), а кириллица внутри формул (Дж, К, кг, `T_{п}`) пропадала из
  PDF — профиль переносит её в `\text{}`.
- Шире полосы A5 (не ошибка сборки): таблица лотереи №6 (В13, В14, В31,
  В32), длинные выключные формулы в решениях (сильнее всего В17/15).
