# Подготовка Ткачук: «Математика — абитуриенту»

Профиль `tkachuk` — В. В. Ткачук. «Математика — абитуриенту» (МЦНМО, 2022).
OCR — Mathpix, `671e0419-d779-4e7d-9083-fb0755eaf5a8.tex`, SHA-256
`a46583dbb3818957d795905e41f529ee5082e5fdb6192063957a29e8ca62981c`;
PDF — `Ткачук 2022.pdf`, SHA-256
`8ad27ea29ddb52d3390c5833a2c3b4de627cfbbd5d40b78e225845894f934e6b`
(скан 959 страниц с текстовым слоем ClearScan; страница PDF = страница
книги + 1).

## Разбор

```bash
./venv/bin/python tools/textbook_parser.py --profile tkachuk \
  --tasks '/путь/к/671e0419-d779-4e7d-9083-fb0755eaf5a8.tex' \
  --output tmp/tkachuk-parse > /dev/null
```

ZIP для партии — `artifacts/tkachuk/tkachuk-images.zip` (рисунки Mathpix и
вырезки из PDF). В интерфейсе «Импорт → Новая партия» профиль называется
«Ткачук».

## Структура книги

- Часть I (справочник) задач не содержит и не импортируется.
- Часть II — 50 уроков в 10 главах (`data/tkachuk_structure.json`:
  названия по оглавлению, уровни, темы). Урок: теория, «Задача N [k].» с
  «Решение.» и «Ответ:» внутри урока, затем «Домашнее задание», ответы и
  указания к которому — в конце книги сплошным потоком «УРОК N. 1. … 2. …».
  - Ключи: задача урока — «У1.3», задача домашнего задания — «Д1.3».
    Пометка уровня «[2]»/«[3]» (уровни 2–3 / только 3) — в номере источника
    («У1.6 [2]»), в условие не попадает. Уровень всего урока («Урок 6 [2]»)
    берётся из таблицы: в шести заголовках OCR его потерял.
  - Путь подборки: «Подготовка к экзамену» → «Глава 1. Тригонометрия» →
    «Урок 1. …» → «Задачи урока» / «Домашнее задание».
  - Во многих уроках книга опускает требование («Во всех задачах опущена
    фраза „решить уравнение“»): условие-формула получает «Решите уравнение
    \(…\).», «Решите неравенство …», «Решите систему уравнений \[…\]» по виду
    формулы; общее требование домашнего задания (урок 25) — из таблицы.
  - Уроки 11, 13, 18, 22, 35, 40 OCR оставил без `\section`: урок ищется по
    строке «Урок N» в начале строки, глава отсекает теорию следующей главы.
  - Раздел ответов: номер ответа часто внутри формулы («…\mathbf{Z} .2\)»,
    «\mathbf{1 5} .»), а Mathpix делает из начала строки «5.» пункт
    `enumerate` и нумерует заново. Поток делится цепочкой номеров 1..N с
    наибольшим весом (`split_stream`): число задач урока известно, пункт
    списка без `\setcounter` — номер с неизвестным значением. Книжное
    указание («Привести уравнение к виду …») — в авторское решение, ответ —
    в авторский ответ; у доказательств и построений всё — в решение.
- Часть III — варианты вступительных экзаменов в МГУ 1970–2021: год →
  факультет (отделение, вариант, поток) → задачи. Ключ «1970.ХФ.3»,
  «2021.ДВИ.В4.2»; коды факультетов — `FACULTY_KEYS`. Ответы — в разделе
  «2. Ответы к вариантам» с сокращёнными подписями («Химический ф-т и отд.
  геофизики геологического ф-та»): подпись сопоставляется с секцией по
  кодам факультетов и порядку книги (`match_answer_blocks`). Секции «Вариант
  был такой же, как на …» задач не дают (список — в диагностике).
  Олимпиадные задачи получают метку «Олимпиада»; параметрические —
  «задача с параметром». Тема — по содержанию условия (`content_topic`).

## Сверка со сканом

Все задачи сверены со сканом агентами по разделам (урок или год;
`artifacts/tkachuk/review/`: инструкция `INSTRUCTIONS.md`, входы `in/`,
отчёты `out/`). У задач уроков условие, авторское решение и ответ
переписаны по скану целиком; у задач ДЗ и вариантов исправлены поля с
расхождениями. Отчёты сводит `artifacts/tkachuk/tools/build_repairs.py`
(баланс скобок и окружений, KaTeX 0.16.11, наличие рисунков) в
`problems/data/tkachuk_repairs.json`, привязанный к SHA-256 TEX.

## Вопросы к владельцу

- Ответы книги, неверные по условию (`artifacts/tkachuk/review/BOOK_ERRORS.md`,
  доводы агентов сверки): ответ книги оставлен как напечатан; маска — по
  книжному ответу или по верному (редакторский ответ с примечанием).
- Олимпиада 2020 г.: все восемь ответов книги не соответствуют условиям
  (по-видимому, напечатаны ответы другого варианта), у 2020.ДВИ.В3.6 —
  ответ от другой задачи.
- Уроки 26–27 и 34: обозначения (\(a, b, c\), \(m_a\), \(R\), \(r\), …)
  заданы во вступлении урока; в уроке 27 в условие каждой задачи добавлена
  строка «В треугольнике \(ABC\) угол \(C\) прямой.», в 26 и 34 — нет.
- Пометки уровня «[2]»/«[3]» — только в номере источника; нужна ли метка.
- Условия-ссылки на соседние задачи (У49.8, Д49.18, Д49.20, Д7.9, Д7.11,
  1973.ГФ.2–3) переписаны редактором самостоятельными
  (`review/editor/editor.json`, с примечанием в `notes`).
