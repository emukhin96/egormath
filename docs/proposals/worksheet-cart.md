# Проект: «корзина» — сборка листка из базы задач

Статус: проект (не реализовано). Пункт 22 плана большой модификации.

## Идея

У каждой задачи в базе — кнопка «добавить в листок» (как корзина в
интернет-магазине). Учитель ходит по каталогу/страницам задач, накидывает
задачи в черновик, затем одной кнопкой превращает подборку в новый листок
(или дополняет существующий).

## Почему это просто сделать

Вся инфраструктура уже есть: листок (`Worksheet`) и его элементы
(`WorksheetItem`) — это и есть «корзина», конструктор листка умеет
переставлять и удалять элементы, а `worksheet_add_task` уже добавляет
задачу в листок по POST. Не хватает только: (а) понятия «текущий листок,
в который добавляем» и (б) кнопки на страницах задач.

## Предлагаемая механика (out-of-the-box, без новых моделей)

1. **Текущий листок** — id в `request.session['cart_worksheet']`.
   Никаких новых таблиц: черновик — это обычный `Worksheet`.
2. **Кнопка «+ в листок»** — в каждой строке каталога `/problems/` и на
   странице задачи. POST на существующий `worksheet_add_task`:
   - если текущий листок не выбран — создаётся новый
     (`title='Новый листок'`) и запоминается в сессии;
   - если выбран — задача добавляется в конец.
   Ответ — JSON для fetch (как в остальных «горячих» действиях),
   плашка «Добавлено в „Название“ (N задач)».
3. **Индикатор корзины** — в topbar рядом с навигацией: название текущего
   листка и счётчик задач, ссылка ведёт в конструктор. Выпадающее меню
   (native `<details>`): «перейти в листок», «выбрать другой листок»,
   «закончить сборку» (очищает сессию).
4. **Дубликаты**: если задача уже есть в текущем листке — кнопка
   показывает «уже в листке» (данные есть в queryset через `annotate`).

## Объём работ

- view: ~20 строк (обёртка над `worksheet_add_task` + сессия);
- topbar-индикатор: context processor (~10 строк) + разметка;
- кнопки в двух шаблонах + маленький JS-обработчик;
- тесты: добавление в новый/существующий листок, счётчик, сброс.

Оценка: один небольшой PR.

## Открытые вопросы

- Нужна ли «мультикорзина» (несколько черновиков параллельно)? Предлагаю
  нет: текущий листок один, переключение через «выбрать другой листок».
- Показывать ли кнопку у задач, уже добавленных в листок, как переключатель
  (повторное нажатие удаляет)? Предлагаю да — это дёшево.
