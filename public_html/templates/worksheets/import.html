Импорт листка из .tex

Предпросмотр структуры перед созданием листка.

Поддерживается формат пакета egor / egormath: шапка \bighead, рубрики \rubr, задачи \task / \taskans, тексты \plaintext. Задачи, текст которых уже есть в базе, будут переиспользованы; новые — сохранены в базу автоматически. Картинки (\includegraphics, \taskpic) автоматически не переносятся: после импорта догрузите файлы на страницах задач — ссылки в тексте вида \taskpic{1} подхватятся по номеру.
