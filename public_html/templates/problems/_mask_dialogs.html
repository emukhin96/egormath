Собрать поле по типу

Для составной маски используйте ручной редактор ниже. Добавление поля не удаляет остальные поля.

Варианты выбора: а|*б (звёздочкой отмечен правильный). Порядок: значения через |. Набор чисел: через ;. Серия: вводите обычным текстом, например πn или \pi*n.

Выражения в любом порядке: через ;. Положительные параметры для выражений: допишите | positive: a,R после эталона, если это следует из условия.
